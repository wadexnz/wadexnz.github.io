# wadexnz.github.io

Source for [wadexnz.github.io](https://wadexnz.github.io/), the personal site of Wade Norman, a backend and integrations engineer in Auckland, New Zealand.

The site is plain HTML and CSS in `index.html`, with no build step, analytics or client-side JavaScript. [Beat Tube](https://wadexnz.github.io/Beat-Tube/) is published separately from [wadexnz/Beat-Tube](https://github.com/wadexnz/Beat-Tube).
