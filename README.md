# Wade Norman's personal site

The landing page at <https://wadexnz.github.io/> is plain HTML and CSS in
`index.html`, published by GitHub Pages from `master`. It has no build step,
external fonts, analytics or client-side JavaScript.

Beat Tube lives separately at <https://wadexnz.github.io/Beat-Tube/>, published
from the `gh-pages` branch of [wadexnz/Beat-Tube](https://github.com/wadexnz/Beat-Tube).
Do not copy the visualiser build into this repository. For the initial move,
publish and verify the new visualiser location before publishing this homepage.

The previous visualiser's generated assets remain temporarily for cached pages;
the landing page does not load them.

CaraLore is a private staging project. Add its public case-study link only once
that case study has been reviewed and published.
